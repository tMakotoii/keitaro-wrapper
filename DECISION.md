# Принятые решения

## Авторизация API вне объёма тестового задания

Репозиторий подготовлен как финальное тестовое задание, а не как production-приложение. В рамках тестового задания отдельную авторизацию и разграничение прав для API не добавляем. Ключ Keitaro хранится только на backend и задаётся через игнорируемый Git файл `.env`.

Это решение ограничивает объём тестового проекта и не означает, что незащищённый API подходит для production. Перед совместным или публичным развёртыванием авторизацию нужно добавить.

## Использование учебного эмулятора Keitaro

Проект подключается к KT Emulator. Ключ API берётся в интерфейсе эмулятора после входа через GitHub. Справочники офферов и связанные справочники доступны только для чтения; создать оффер через эмулятор нельзя.

## Закрепление долей офферов

Закреплённые целые доли хранятся локально. При применении изменений закреплённые доли остаются фиксированными, а оставшийся процент распределяется поровну между незакреплёнными активными офферами. Итоговая сумма должна быть ровно 100%.
